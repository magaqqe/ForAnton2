    Переменная — это просто «коробка»,
в которой хранится значение.

к примеру int age = 18;
age - коробка
18 - значение внутри

    Типы
int	 - целые числа
double - дробные числа
string - текст
char - один символ
bool - true / false

    Обьект - хранит сразу несколько данных

    Ссылка — это не сам объект, 
    а «адрес», где объект лежит в памяти
