bin - папка в которой содержатся артефакты
obj - хранит кэш переменных

Thread.Sleep(500); - задержка между выполнениями оставшейся части кода 0.5сек


Если не использовать функцию, выйдет уведомление об этом, но ошибки не будет

Важен ли порядок определения функций? Нет, не важен
Возможно ли сослаться из функции, определенной раньше в файле, к функции, определенной после? Да, можно, у вас в видео есть пример

.git
он был уже у меня установлен с предыдущих занятий, командой git проверил это
командой git init добавляю гит к проэкту
в папку .gitignore добавляю bin и obj чтоб они не отслеживалисить git-ом

командами
git config --global user.name "Dmitry"
git config --global user.email "playpplay8@gmal.com"
конфигурирую пользователя
из-за --global пользователь конфигурируется для всей системы и не нужно это делать еще раз
командой git add . добавил все файлы

git add .           
git commit -m "dada"

если не добавить сначала все измененые файлы то commit ругается и просит все добавть

мы можем вернуть что-то из комита при помощи команды git restore .
если мы перешли на новый комит, а нам нужно проверить какие-то файлы со старого, нужно
использовать git log чтоб увидеть какие комиты есть
после используем git checkout и вставить выбраный хэш
командой git checkout master мы возвращаемся на последний комит
так же командой git checkout -b название   мы можем создать еще одну ветку для каких-то 
экспериментов или т.п
git rebase название ветки может помочь нам переслать данные с одной ветки в другую

после чего использую команду git remote add https://github.com/magaqqe/ForAnton2.git
